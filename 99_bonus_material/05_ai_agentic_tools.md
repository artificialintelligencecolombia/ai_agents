# AI Agent Tools & Platforms

## Code-First Agent Frameworks

LangGraph – Graph-based framework for durable, stateful multi-step agent workflows
CrewAI – Role-based multi-agent orchestration framework
Microsoft Agent Framework – Unified successor to Semantic Kernel + AutoGen, with native MCP support
AutoGen / AG2 – Multi-agent conversation framework for research-style agent collaboration
LlamaIndex Workflows – Agentic workflow layer built on LlamaIndex's RAG/data foundation
Pydantic AI – Type-safe agent framework for Python/FastAPI teams
Haystack Agents – Pipeline-based agent orchestration evolved from a RAG framework
Claude Agent SDK – Anthropic's SDK for building agents with hierarchical subagents
OpenAI Agents SDK / Responses API – OpenAI's toolkit for building and orchestrating agents
Rasa – Open-source framework for private, self-hosted conversational agents
Semantic Kernel – Microsoft's earlier agent SDK, now folded into Microsoft Agent Framework
FastAgency – Lightweight framework for deploying multi-agent workflows to production

## No-Code / Low-Code Builders

n8n – Visual workflow automation tool with AI agent nodes, self-hostable
Lindy – No-code platform for building business-automation agents
Dify – Open-source visual builder for LLM apps and agents
AutoGPT – Open-source autonomous agent builder with visual workflows
OpenAI Agent Builder – OpenAI's no-code agent creation platform
Crew AI Studio – No-code interface layered on top of the CrewAI framework
Gumloop – Visual automation builder for AI-powered workflows
Zapier Agents – Agent builder integrated into Zapier's automation ecosystem
Make – Visual automation platform with AI agent capabilities

Microsoft Copilot Studio / Microsoft 365 Agents – Enterprise agent builder integrated with Microsoft 365
AWS Bedrock AgentCore – Amazon's managed infrastructure for deploying production agents
Google Vertex AI Agent Builder – Google Cloud's enterprise agent development platform
Salesforce Agentforce 360 – Salesforce's enterprise agent platform for CRM workflows
Claude Code – Anthropic's agentic coding tool
ChatGPT Agent – OpenAI's consumer/enterprise task-executing agent
Devin AI – Autonomous AI software engineer for coding tasks
Perplexity Computer – Multi-model orchestration agent platform
Google Antigravity – Agent-first development platform from Google
Manus – Platform focused on autonomous task execution

## Voice AI / Conversational Agent Platforms

ElevenLabs – Voice generation and cloning platform, strong for studio-grade content
Cartesia – Low-latency (~90ms) voice model provider with a dedicated voice-agent platform ("Line")
Deepgram – Combined STT+TTS API optimized for real-time conversational agents
Inworld AI – Top-ranked TTS/STT platform built for real-time interactive AI
Vapi – Developer platform for building real-time voice AI agents
Synthflow – No-code voice agent builder for business calling
Amazon Lex – AWS conversational interface builder with NLU
Twilio Voice – Programmable voice/telephony infrastructure for voice agents
Leaping AI – Enterprise voice agent platform for customer service/scheduling
Murf AI – TTS platform for marketing, e-learning, and voiceover content
PlayHT – TTS platform with strong multilingual and telephony support
Descript – Transcript-based audio/video editor with voice AI features
Resemble AI – Voice cloning platform with EU AI Act watermarking compliance
Chatterbox – Open-source (MIT) TTS model competitive with ElevenLabs
Kokoro – Lightweight, CPU-friendly open-source TTS model

## Infrastructure & Protocols

MCP (Model Context Protocol) – Standard for connecting agents to tools and data sources
A2A (Agent2Agent) – Emerging protocol for agent-to-agent communication
Azure AI Foundry – Guardrail layer (task adherence, PII protection, prompt-injection defense) for deployed agents
